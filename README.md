# AI Engineering Journey

A hands-on collection of AI engineering experiments and projects covering large language models, tool calling, LangChain, RAG, AI agents, MCP, and production AI systems.

This repository documents my progression through a structured AI Engineering learning program, with an emphasis on understanding core concepts and building working systems.

## Learning Areas

- LLM fundamentals
- Prompting and model interaction
- Tool calling
- LangChain
- Retrieval-Augmented Generation (RAG)
- Agentic AI
- Model Context Protocol (MCP)
- Production AI systems
